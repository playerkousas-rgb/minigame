# 出門玩 · Pocket Play

一個以手機為中心、無需網路也能使用的聚會小工具箱。

## 內容

- **骰子 / 大話骰**：可設定 1–12 顆、2–100 面；骰面預設全黑，按住骰子查看結果，手機需搖動才會換骰。
- **幸運輪**：自訂最多 12 個獎勵、懲罰或任務，也附有聚會、獎勵、懲罰範本。
- **隨手工具**：隨機抽選、硬幣、猜拳裁判、雙隊計分板與活動倒數。
- 所有自訂內容使用瀏覽器 `localStorage` 儲存，不需登入；Service Worker 會快取 App Shell 以支援離線使用。

## 本機預覽

這是無依賴的靜態網頁，不需要安裝套件。用任何靜態伺服器啟動即可，例如：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Service Worker 需要透過 `http://` 或 `https://` 載入；直接雙擊 `index.html` 仍可使用所有遊戲功能，只是瀏覽器不會啟用離線快取。
