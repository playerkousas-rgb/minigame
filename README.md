# 出門玩 · Pocket Play

一個以手機為中心、無需網路也能使用的聚會小工具箱。

> **目前版本：v1.2.0**（零 npm 依賴、離線 PWA、單一靜態 bundle 約 862 KB）
> 交付前自檢：`npm run check`（14 項）· 建置：`npm run build` · 本機預覽：`npm start`
> 可「加入主畫面」當 App 用；有新版本會出現「立即更新」，唔會玩到一半被偷偷換版。
> 更新紀錄：[CHANGELOG.md](CHANGELOG.md) · 授權：[MIT](LICENSE)

## 首頁：四大分類

遊戲與工具分開排好，首頁就是 2×2 的四大方格（手機正好一版四格），點進分類再挑要玩的遊戲：

1. **🎲 骰子遊戲**：骰子工具、大話骰、多人骰子房
2. **🃏 卡牌遊戲**：德州撲克（NEW）、21 點（NEW）、百家樂（NEW）、機密特務
3. **💬 對話遊戲**：狼人殺、一夜狼人、誰是臥底 / 間諜危機
4. **🧰 小工具**：幸運輪、隨機分隊、硬幣、多人計分板、活動倒數

**每一款遊戲（含工具）都附「📖 玩法說明書」**：進入遊戲先看到目標、人數、準備、流程、勝負與小提示，像開 board game 的說明書一樣，不用先上網查規則。

## 當 App 用：加入主畫面 · 一鍵更新

- **加入主畫面**：首頁的「📲 加入主畫面」按鈕。Android／Chrome 會叫用系統安裝提示；iPhone／iPad 會彈出三步教學（分享 → 加入主畫面 → 加入）。已經用主畫面開啟時自動隱藏。
- **版本更新**：Service Worker 偵測到新版本時，畫面底部會出現「✨ 有新版本可用 — 立即更新 / 稍後」。按「稍後」不會再吵你；按「立即更新」才會換版並自動重新載入，本機資料與分數保留（連線中的房間會斷開，重新加入即可）。
- 更新檢查時機：每次回到前景、重新連線、以及每 30 分鐘一次；不會在背景偷換版。

## 卡牌遊戲（多人 + 單機）

三款賭場撲克都支援 **📱 多人連線（掃 QR、每人一機、2–8 人）** 與 **單機人機** 兩種模式，發牌一律使用瀏覽器 **Crypto RNG（加密級隨機源）**——由莊家手機統一洗牌發牌，每局獨立、無法預測或動手腳；牌桌顯示「剩餘張數 · 洗牌種子 #XXXX」供核對。

**多人連線方式（三款相同）**：莊家手機進入遊戲 → 切「📱 多人連線」→ 設定人數 → 建立房間 → 其他人掃各自的 QR 加入。德州撲克與 21 點由莊家手機主持、依座位輪流行動；百家樂由莊家發牌開牌、牌手各自押注。需要網路（PeerJS 點對點，不需帳號），也可離線時用單機人機模式。

- **德州撲克**：2–8 人同桌（或單機 vs 電腦），盲注 5/10、每人 1000 枚籌碼。翻牌前 → 翻牌 → 轉牌 → 河牌 → 攤牌，支援棄牌、過牌、跟注、加注（最小大盲 ×2）、全下、自動跑牌與**邊池結算**；莊家按鈕每局輪流、未跟注的超額下注自動退回。
- **21 點**：6 副牌鞋、莊家 17 點以上停牌（含軟 17）、黑傑克 3:2、只有前兩張可「加倍 ×2」；牌手先下注鎖定、莊家發牌後按座位要牌／停牌。不設保險與分牌。牌剩不到 1 副自動重洗。
- **百家樂**：8 副牌鞋、完整賭場補牌表（含莊家第三張規則）、天生 8/9 不補牌；押閒 1:1、押莊 1:0.95（5% 抽水自動扣）、押和 8:1；路單記錄最近 12 局（閒／莊／和），同步給所有牌手。

單機模式的籌碼與戰績存於 `localStorage`；多人局籌碼由莊家手機管理，隨時可結束房間。

## 原有內容

- **骰子 / 大話骰**：可設定 1–12 顆、2–100 面；骰面預設全黑，按住骰子查看結果，手機需搖動才會換骰。也可建立**多人骰子房間**（需網路）：每人掃 QR 加入後，誰搖手機骰子就同步出現在所有人的桌上；房主可切換「公開」或「隱藏（大話骰）」骰面，並可一鍵「全部重骰」開始新回合。
- **幸運輪**：自訂最多 12 個獎勵、懲罰或任務，也附有聚會、獎勵、懲罰範本。
- **外出小工具**：隨機分隊、硬幣、支援 2–12 個玩家／隊伍的多人計分板與活動倒數；計分板可為每位玩家分別輸入本局分數，再按加分或扣分。
- **多人連線記分**（需網路）：在計分板點「建立記分房間」，會產生每位玩家的 QR Code；其他人用手機掃自己的 QR，就能在自己手機上記自己的分，並即時看到所有玩家的分數（透過 PeerJS 點對點同步，不需伺服器、不需帳號）。
- **狼人殺**（需網路）：**版本 A–D（6 / 8 / 10 / 12 人）預設局**或自訂角色配置，每人掃 QR 秘密發牌，手機就是角色卡；主持人端有身份總覽（貓紙），可一鍵語音導播夜晚流程（天黑請閉眼 → 狼人 → 守衛 → 女巫解藥/毒藥 → 預言家 → 天亮）並自動計時，白天用手機投票計票、處理獵人開槍、白痴翻牌與遺言。也支援**離線單機**（見下方）。
- **誰是臥底 / 間諜危機**（需網路）：**版本 A 誰是臥底**（臥底拿到相似詞）與**版本 B 間諜危機**（間諜不知道地點）兩種玩法，內建 **12 個主題**（派對／飲食／生活／職場／旅遊／科技生活／人物身份／動物／娛樂影視／自然天氣／學校／健康）共 130+ 組詞對，也可自訂詞；每人掃 QR 收到秘密詞，討論倒數計時後用手機投票抓臥底，主持人一鍵揭曉結果。
- **一夜狼人**（需網路）：一晚定勝負的快節奏狼人殺，**版本 A–D（4 / 5 / 6 / 8 人）預設局**或自訂角色；夜晚狼人相認、預言家查驗、強盜換牌、搗蛋鬼換兩家、失眠者確認身份，天亮後手機投票，揪出現在真正的狼人。
- **機密特務（Codenames）**（需網路）：25 詞 5×5 棋盤、紅藍兩隊各一位隊長；只有隊長的手機看得到答案卡（紅 9 / 藍 8 / 中立 7 / 炸彈 1），隊員只看到詞面。隊長**直接開口說出提示（詞 + 數字）**，主持人輸入、隊員點詞作答，猜中炸彈直接輸；內建 **14 個主題**（通用／動物／食物／城市／科技／電影娛樂／大自然／身體／運動／音樂／職業／場所／交通工具／國家）各 26 詞或自訂 25 詞，主持人端有答案卡全見面板。
- 所有自訂內容使用瀏覽器 `localStorage` 儲存，不需登入；Service Worker 會快取 App Shell 以支援離線使用。離線時可用本機記分板，多人連線記分則需要網路。

## 語音導播

語音導播預設使用**廣東話（粵語）**。首頁右上角可切換「廣東話／普通話」及開關語音；實際可用聲音由裝置的瀏覽器 Web Speech API 提供。若裝置沒有安裝廣東話語音，瀏覽器會依 `zh-HK` 語言標籤使用備用聲音，建議在手機系統的朗讀／語音設定下載廣東話語音包。

## 本機預覽

這是零依賴的靜態網頁，**不需要 `npm install`**：

```bash
npm start                 # node tools/serve.mjs → http://0.0.0.0:4173
PORT=8080 npm start       # 換 port
```

`tools/serve.mjs` 只用 Node 內建模組（不用 `npx serve` 上網下載），會回正確 MIME、阻擋路徑穿越、把乾淨網址 fallback 到 `index.html`，並對 `/_vercel/*` 回 204。

Service Worker 需要透過 `http://` 或 `https://` 載入；直接雙擊 `index.html` 仍可使用所有遊戲功能，只是瀏覽器不會啟用離線快取。

## 交付前自檢（14 項）

```bash
npm run check    # tools/verify.mjs：版號、module 用法、語法、引用檔案、圖標、manifest、ID／ARIA 對照、安裝與更新流程、CSP、體積、死重、secret
npm run lint     # 同上，連 vendor 都做語法檢查
npm run build    # 先自檢，再把 5 個檔案＋icons/＋vendor/ 整理到 public/
npm run icons    # 需要 ImageMagick；重新產生 icons/ 9 個圖標（日常建置不需要）
```

自檢會擋住幾種「看起來正常、上線即死」的情況，例如：

- `app.js` 是傳統 `<script defer>`，卻加了 top-level `import`（瀏覽器即 SyntaxError，整個 App 白畫面）。
- `package.json`／`index.html`（meta＋頁尾）／`app.js`／`sw.js` 版號不一致。
- HTML／manifest／Service Worker 指去不存在的檔案，或圖標尺寸不對。

CI 亦會在每次 push／PR 跑同一套（[.github/workflows/check.yml](.github/workflows/check.yml)）。

## 部署（Vercel）

- `vercel.json`：`framework: null`、`buildCommand: npm run build`、`outputDirectory: public`，只部署建置產物；`package.json`、`tools/`、`*.md` 不會派街。
- 安全標頭：CSP（`script-src 'self'`、`frame-ancestors 'none'`）、`X-Content-Type-Options`、`Referrer-Policy`、`Permissions-Policy`；`sw.js`／manifest 用 `must-revalidate`，`vendor/` 長快取，`icons/` 一星期。
- **Vercel Web Analytics** 用靜態 snippet（`/_vercel/insights/script.js`，見 `index.html`），不要再加 npm 套件；在 Dashboard → Analytics 開啟即可。它是無 cookie 的彙總流量統計，不會讀寫 `localStorage`、也不影響離線；不想收集就刪掉 `index.html` 那一行 `<script>`。
- **分享預覽圖**：`index.html` 的 `og:image` 現時是相對路徑；首次部署後請改成 `https://<你的網域>/icons/og-image.png`（絕對網址），WhatsApp／Signal 才會有預覽圖。
- **Deployment Protection**：若專案開了 Vercel Authentication，朋友掃 QR 會被要求登入而無法加入房間；多人連線前請在 Vercel 專案設定關閉，或改用公開網域。

## 離線版本（已完成）

**本來就離線可用**：骰子、幸運輪、隨手工具（分隊／硬幣／計分板）、活動倒數——載入過一次之後，Service Worker 會快取整個 App Shell，沒網路也能用。

**四款多人遊戲的「離線單機模式」（已完成）**：狼人殺、誰是臥底、一夜狼人、機密特務都支援一台手機開局。建立房間時選「**📴 離線單機**」即可：

- **不連 PeerJS、不發 QR**：沒網路、沒訊號也能玩，全場只需要主持人一台手機。
- **發牌／發詞改為輪流傳手機**：畫面先顯示一張黑色交接牌「請把手機交給 XX」，本人拿起手機點一下才看得到自己的秘密身份，看完蓋牌傳給下一位；輪到自己時還可以順手改顯示名稱。發牌期間主持人面板會自動隱藏身份總覽（貓紙），避免傳手機時暴雷。
- **夜晚行動由主持人代點**：角色本人睜眼用手比，主持人代為點選；查驗／換牌結果以「點一下才顯示」的秘密卡呈現，只給當事人看。
- **投票改為主持人代投**：畫面列出黑色小卡名牌，輪到的玩家用手指比、主持人點卡收票（動靜最小），可棄權、可「重收上一票」，收齊後自動計票、揭曉。
- **螢幕保持常亮**：離線局自動啟用 Screen Wake Lock（不支援的裝置自動略過），傳手機過程不會熄屏。
- **勝負與流程引擎完全共用線上版邏輯**：狼人殺的夜晚結算／獵人開槍／白痴翻牌、一夜狼人的換牌與揭曉、機密特務的翻牌計分與炸彈判定，離線與線上走同一套程式碼。

**機密特務離線版**：傳手機看隊伍時，隊長會看到完整答案卡（記好後蓋牌）；遊戲中隨時可點「🔴／🔵 隊長看答案卡」攤開給隊長偷看，隊員喊詞後主持人直接點棋盤代翻。

離線單機與掃 QR 連線可在建立前自由切換；多人連線（PeerJS + QR）功能不變。

## 專案瘦身與防增肥維護規範（Vercel 部署守則）

為避免 Vercel 部署儲存空間配額爆滿或隨改版逐漸臃腫，請嚴格遵守以下「極致防增肥」原則：

1. **零死重與孤立資產控管**：
   - 新增靜態資產（圖檔、音效等）前，必須確認已在代碼或 HTML/CSS 中引用。
   - 避免引入未經壓縮的大型點陣圖檔（PNG/JPG），優先採用向量 SVG、CSS 純代碼繪製或系統 Emoji。
   - 定期檢查並清除未引用的孤立檔案、原稿設計圖與截圖。

2. **禁止遺留備份與暫存檔**：
   - 本地開發時嚴禁將 `*.bak`、`*.tmp`、`*.old`、`*.swp` 或編輯器暫存檔提交入版本庫。
   - 根目錄已配置嚴格的 `.gitignore` 與 `.vercelignore`，禁止忽略規則失效。

3. **極簡依賴原則（Zero / Minimal Dependencies）**：
   - 本專案核心設計為零依賴純前端靜態 Web App。
   - 嚴禁隨意在 `package.json` 的 `dependencies` 加入肥大套件。
   - 若未來引入建置工具（如 Vite、Tailwind CLI），必須**一律放入 `devDependencies`**，確保生產部署不會上傳或快取龐大的 Node 執行期依賴。

4. **Vercel 部署過濾機制**：
   - 依賴根目錄的 `.vercelignore` 精確過濾 `.git/`、測試代碼（`_qa/`、`tests/`）、暫存檔、說明文檔與日誌，防止建置快取與部署配額溢出。
   - 部署時依據 `vercel.json` 進行快取與標頭優化（如 Service Worker `must-revalidate`、`vendor` 庫長效快取 `max-age=31536000, immutable`）。

5. **版本驗證與防退化檢查**：
   - 每次改版與交付前，必須執行以下指令進行語法與無依賴驗證：
     ```bash
     npm run check
     npm run lint
     npm run build
     ```
   - 改版號要四個地方一齊改：`package.json`、`index.html`（meta＋頁尾）、`app.js`、`sw.js`（`npm run check` 會對照）。
   - 嚴格確保既有功能、邏輯、離線 PWA、PeerJS 多人連線與各款遊戲 100% 正常運作。

6. **零 npm 依賴（v1.1.0 起）**：
   - `dependencies` 已經清空；不要為了一個小功能引入套件（包括 analytics、UI library）。第三方程式碼一律放 `vendor/` 並自行鎖版本。
   - `app.js` 是傳統 script：**不可**加 top-level `import`／`export`；要改用 ESM 就同時改 `index.html` 的 `<script type="module">`，並確保 vendor 先執行。
