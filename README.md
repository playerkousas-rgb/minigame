# 出門玩 · Pocket Play

一個以手機為中心、無需網路也能使用的聚會小工具箱。

## 內容

- **骰子 / 大話骰**：可設定 1–12 顆、2–100 面；骰面預設全黑，按住骰子查看結果，手機需搖動才會換骰。也可建立**多人骰子房間**（需網路）：每人掃 QR 加入後，誰搖手機骰子就同步出現在所有人的桌上；房主可切換「公開」或「隱藏（大話骰）」骰面，並可一鍵「全部重骰」開始新回合。
- **幸運輪**：自訂最多 12 個獎勵、懲罰或任務，也附有聚會、獎勵、懲罰範本。
- **外出小工具**：隨機分隊、硬幣、支援 2–12 個玩家／隊伍的多人計分板與活動倒數；計分板可為每位玩家分別輸入本局分數，再按加分或扣分。
- **多人連線記分**（需網路）：在計分板點「建立記分房間」，會產生每位玩家的 QR Code；其他人用手機掃自己的 QR，就能在自己手機上記自己的分，並即時看到所有玩家的分數（透過 PeerJS 點對點同步，不需伺服器、不需帳號）。
- **狼人殺**（需網路）：**版本 A–D（6 / 8 / 10 / 12 人）預設局**或自訂角色配置，每人掃 QR 秘密發牌，手機就是角色卡；主持人端有身份總覽（貓紙），可一鍵語音導播夜晚流程（天黑請閉眼 → 狼人 → 守衛 → 女巫解藥/毒藥 → 預言家 → 天亮）並自動計時，白天用手機投票計票、處理獵人開槍、白痴翻牌與遺言。也支援**離線單機**（見下方）。
- **誰是臥底 / 間諜危機**（需網路）：**版本 A 誰是臥底**（臥底拿到相似詞）與**版本 B 間諜危機**（間諜不知道地點）兩種玩法，內建 **12 個主題**（派對／飲食／生活／職場／旅遊／科技生活／人物身份／動物／娛樂影視／自然天氣／學校／健康）共 130+ 組詞對，也可自訂詞；每人掃 QR 收到秘密詞，討論倒數計時後用手機投票抓臥底，主持人一鍵揭曉結果。
- **一夜狼人**（需網路）：一晚定勝負的快節奏狼人殺，**版本 A–D（4 / 5 / 6 / 8 人）預設局**或自訂角色；夜晚狼人相認、預言家查驗、強盜換牌、搗蛋鬼換兩家、失眠者確認身份，天亮後手機投票，揪出現在真正的狼人。
- **機密特務（Codenames）**（需網路）：25 詞 5×5 棋盤、紅藍兩隊各一位隊長；只有隊長的手機看得到答案卡（紅 9 / 藍 8 / 中立 7 / 炸彈 1），隊員只看到詞面。隊長**直接開口說出提示（詞 + 數字）**，主持人輸入、隊員點詞作答，猜中炸彈直接輸；內建 **14 個主題**（通用／動物／食物／城市／科技／電影娛樂／大自然／身體／運動／音樂／職業／場所／交通工具／國家）各 26 詞或自訂 25 詞，主持人端有答案卡全見面板。
- 所有自訂內容使用瀏覽器 `localStorage` 儲存，不需登入；Service Worker 會快取 App Shell 以支援離線使用。離線時可用本機記分板，多人連線記分則需要網路。

## 本機預覽

這是無依賴的靜態網頁，不需要安裝套件。用任何靜態伺服器啟動即可，例如：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Service Worker 需要透過 `http://` 或 `https://` 載入；直接雙擊 `index.html` 仍可使用所有遊戲功能，只是瀏覽器不會啟用離線快取。

## 離線版本（已完成）

**本來就離線可用**：骰子、幸運輪、隨手工具（分隊／硬幣／計分板）、活動倒數——載入過一次之後，Service Worker 會快取整個 App Shell，沒網路也能用。

**四款多人遊戲的「離線單機模式」（已完成）**：狼人殺、誰是臥底、一夜狼人、機密特務都支援一台手機開局。建立房間時選「**📴 離線單機**」即可：

- **不連 PeerJS、不發 QR**：沒網路、沒訊號也能玩，全場只需要主持人一台手機。
- **發牌／發詞改為輪流傳手機**：畫面先顯示一張黑色交接牌「請把手機交給 XX」，本人拿起手機點一下才看得到自己的秘密身份，看完蓋牌傳給下一位；輪到自己時還可以順手改顯示名稱。發牌期間主持人面板會自動隱藏身份總覽（貓紙），避免傳手機時暴雷。
- **夜晚行動由主持人代點**：角色本人睜眼用手比，主持人代為點選；查驗／換牌結果以「點一下才顯示」的秘密卡呈現，只給當事人看。
- **投票改為主持人代投**：畫面列出黑色小卡名牌，輪到的玩家用手指比、主持人點卡收票（動靜最小），可棄權、可「重收上一票」，收齊後自動計票、揭曉。
- **螢幕保持常亮**：離線局自動啟用 Screen Wake Lock（不支援的裝置自動略過），傳手機過程不會熄屏。
- **勝負與流程引擎完全共用線上版邏輯**：狼人殺的夜晚結算／獵人開槍／白痴翻牌、一夜狼人的換牌與揭曉、機密特務的翻牌計分與炸彈判定，離線與線上走同一套程式碼。

**機密特務離線版**：傳手機看隊伍時，隊長會看到完整答案卡（記好後蓋牌）；遊戲中隨時可點「🔴／🔵 隊長看答案卡」攤開給隊長偷看，隊員喊詞後主持人直接點棋盤代翻。

離線單機與掃 QR 連線可在建立前自由切換；多人連線（PeerJS + QR）功能不變。
